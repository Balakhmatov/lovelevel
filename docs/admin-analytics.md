# Админка MatchLove

Кнопка «Админка» появляется после входа в аккаунт, ID которого уже внесён в `ADMIN_USER_IDS` в `/etc/lovelevel/app.env`. Используется существующая проверка администраторов, новые роли автоматически не выдаются. После изменения переменной нужен перезапуск только сервиса lovelevel.

Разделы: аналитика за 7/30/90 дней, последние 100 участников, открытые жалобы с контекстом и закрытием обращения. Endpoint аналитики и список участников проверяют серверную сессию и ID администратора; ответы не кешируются.

Посетитель — случайный идентификатор браузера в localStorage. Сессия создаётся при открытии вкладки, смене аккаунта или возвращении после 30 минут без heartbeat. Перезагрузки и разные вкладки считаются отдельными сессиями. Интервалы до 30 секунд учитываются только в видимой вкладке с действием за последнюю минуту; сервер ограничивает начисление реально прошедшим временем. Это оценка активного времени, а не точный секундомер. Вкладки одного браузера дают одного посетителя и несколько сессий.

В аналитике сохраняются UTM source/medium/campaign, домен внешнего реферера и путь входа без query-параметров. Сырые URL, IP и содержимое анкеты или переписки в события аналитики не записываются. Участник привязывается к сессии после входа; повторная авторизация начинает новую сессию. Источник регистрации — первый известный источник привязанной к аккаунту сессии, а не рекламная атрибуция с полным восстановлением пути анонимного посетителя. Источники без регистрации остаются видны в трафике.

Воронка строится по аккаунтам, зарегистрированным за выбранный период: регистрация → анкета → исходящий лайк → взаимный мэтч → отправленное сообщение. Этапы проверяются по текущему состоянию данных и последовательно; последующие действия могут быть совершены позднее регистрации. Уже удалённые аккаунты не входят в воронку. События показывают успешные действия за период; повторные успешные запросы входят в число действий.

D1/D7 — возврат в соответствующий календарный день после регистрации по Москве. В знаменателе только аккаунты, для которых нужный день полностью завершён. Администраторы исключены из агрегатов после авторизации. Старые регистрации, лайки и переписки доступны из существующих таблиц; посещаемость, источники, активное время и события собираются только с момента обновления.

Из переписки доступно меню «⋯»: жалоба и блокировка. Жалоба может сразу блокировать собеседника; в контекст прикладывается последнее входящее сообщение этой переписки. Заблокированный не может писать, ставить лайки или читать чат в обоих направлениях. В профиле есть список блокировок и разблокировка; собственная разблокировка не снимает блокировку, поставленную другой стороной. Контроль применяется на сервере.

Развёртывание не меняет цены, сроки доступа и приём платежей.
